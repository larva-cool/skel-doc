# 商业授权

Ai Forge 企业级项目套件采用 [AGPL-3.0](https://www.gnu.org/licenses/agpl-3.0.html) 开源协议发布。在遵守 AGPL 条款的前提下，你可以免费使用本套件的全部功能。

如果你的使用场景**不希望履行 AGPL 开源义务**（例如闭源交付、SaaS 商业化运营、二次开发后不想公开源码），则需要购买商业授权。

| 版本 | 价格 | 授权方式 |

| 商业授权 | **¥999**（一次性付费） | 按授权主体永久授权，不限项目数量 |

- 虚拟商品，付款交付后不支持退款

## 商业授权权益

购买商业授权后，你获得以下权利：

1. **闭源使用**：可在商业项目中闭源使用本套件，无需公开衍生作品源码
2. **SaaS 运营**：可将基于本套件开发的系统以 SaaS / 网络服务形式对外提供，无需向用户提供源码
3. **外包交付**：可将基于本套件开发的项目闭源交付给客户
4. **永久更新**：一次性付费，授权主体可永久获取并使用后续版本
5. **不限项目数**：同一授权主体下的项目数量不限

## 使用限制

- 商业授权不免除保留原作者版权声明与许可声明的义务
- 禁止将本套件源码本身作为产品进行转售、二次分发或许可给第三方（例如打包成"XX 框架"对外售卖）
- 授权主体须为购买时登记的个人或公司，授权不得转让

## 常见问题

**Q：开源版和商业版功能有区别吗？**

没有。两者代码完全一致，区别仅在于授权条款。

**Q：一个公司多个项目需要购买多份吗？**

不需要。商业授权按主体授权，同一主体下的项目数量不限。

**Q：个人名义购买后，所在公司的项目能用吗？**

授权跟随购买时登记的主体。个人名义购买的授权仅限本人使用，公司项目需以公司名义购买。

**Q：可以开发票吗？**

暂不支持。

**Q：未购买商业授权但已经闭源商用了怎么办？**

请及时联系作者补购授权。未经授权的闭源商用行为属于对 AGPL-3.0 协议的违反，我们保留追究的权利。
