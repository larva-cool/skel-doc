# 项目概述与产品定位

## 1. 项目背景

Ai Forge 是一套企业级项目套件，旨在为开发者提供快速构建高质量应用的基础框架。套件包含：

- **Ai Forge API**：后端 API 服务，基于 Laravel 13.x 构建，采用领域驱动设计（DDD）架构，内置完整的管理员/用户双端认证、RBAC 权限管理、后台管理系统与 AI 助手能力
- **Ai Forge Admin**：管理后台前端（Vue 3 + TypeScript + Element Plus SPA）
- **Ai Forge 文档站**：产品与技术文档（即本站）

其他信息：

- **官方站点**：<https://www.aiforge.cn>
- **演示后台**：<https://admin-demo.aiforge.cn>
- **本地开发域名**：`http://laravel-skel-forge.test`（Laravel Herd 自动提供）

## 2. 项目目标

- 提供开箱即用的企业级 API 开发模板
- 集成成熟的认证、授权和权限管理方案
- 支持多用户系统（管理员+前台用户，双 Guard 隔离）
- 内置常用的系统管理功能（用户、角色、菜单、配置、地区、附件、验证码、通知、审计）
- 集成 AI Agent 能力，为后台提供智能助手
- 内置完整的监控、队列、定时任务、调度日志体系
- 提供完整的开发、测试和部署方案

## 3. 目标用户

| 用户类型 | 说明 |
|---------|------|
| 后端开发人员 | 快速搭建 API 服务 |
| 技术团队 | 统一技术栈和开发规范 |
| 初创企业 | 快速构建 MVP 产品 |
| 教育机构 | 学习 Laravel 最佳实践 |

## 4. 产品定位

### 4.1 产品类型

企业级 API 开发框架模板（可直接作为 APP 项目的后端起点）

### 4.2 核心价值

| 核心价值 | 说明 |
|---------|------|
| **快速启动** | 一键安装和配置，快速开始开发 |
| **安全可靠** | 内置完整的认证和权限体系 |
| **架构清晰** | 采用 DDD 分层架构，代码组织规范 |
| **功能完整** | 包含常用的系统管理、监控、AI 能力 |
| **易于扩展** | 模块化设计，易于添加新功能 |
| **实时通信** | Laravel Reverb + Echo 提供 WebSocket 能力 |

### 4.3 市场定位

| 维度 | 定位 |
|------|------|
| 技术层次 | 中高级后端开发框架 |
| 应用场景 | APP 后端服务、企业管理系统、电商后台、SaaS 服务 |
| 目标规模 | 中小型到大型企业级应用 |

### 4.4 作为 APP 后端起点

前台 API v1 已覆盖 APP 业务的基础能力，拿到手后只需实现具体业务逻辑，无需从地基搭起：

| 能力域 | 已具备的接口 |
|--------|-------------|
| 账户 | 注册登录（手机/邮箱/微信/Apple）、Token 刷新、账户注销 |
| 用户中心 | 资料、头像（自动转 WebP）、联系方式、密码、VIP、积分/金币流水、社交账号、登录历史、实名认证 |
| 资产 | 钱包概览、流水、充值下单与订单查询、提现申请 |
| 增长与留存 | 任务中心（进度查询、领奖）、邀请关系与统计、访问记录（PV/UV、最近浏览） |
| 内容与互动 | 多态点赞/收藏/关注/评论、Banner、公告、协议 |
| 服务与合规 | 通知、收货地址、反馈提交、举报提交 |
| AI 接入 | MCP Server（`/mcp/v1`），C 端能力直接被 AI 客户端调用 |
